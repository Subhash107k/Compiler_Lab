# 🖥️ Compiler Lab

> A comprehensive collection of **Compiler Design Laboratory Experiments** implemented using **C Programming**, **Flex (Lex)**, and **Bison (Yacc)**. This repository demonstrates the fundamental concepts of compiler construction, including lexical analysis, parsing, token recognition, syntax validation, and expression evaluation.

# 📖 Overview

This repository contains a series of laboratory experiments for the **Compiler Design** course. Beginning with basic C programming and progressing to lexical analysis and parser generation, each lab introduces essential compiler concepts through practical implementations using **GCC**, **Flex**, and **Bison**.

The repository is intended for students learning compiler construction and serves as a practical reference for implementing the front-end phases of a compiler.

# 📚 Laboratory Experiments

## 🔹 Lab 1 — Basic C Programming

Introduction to C programming through simple console applications.

### Programs

* `sum_program.c`
* `circle_area.c`

### Concepts Covered

* Program structure
* Variables and data types
* User input and output
* Arithmetic operators
* Mathematical calculations
* GCC compilation

---

## 🔹 Lab 2 — Lexical Analyzer Using Flex

A basic lexical analyzer that scans C source code and identifies different categories of tokens.

### File

* `tokenizer.l`

### Recognized Tokens

* Keywords
* Identifiers
* Constants
* Operators
* Delimiters

### Concepts Covered

* Lexical analysis
* Regular expressions
* Pattern matching
* Token generation
* Compiler front-end

---

## 🔹 Lab 3 — Token Counter Using Flex

A lexical analyzer that recognizes programming language tokens and generates statistical reports.

### Files

* `token_counter.l`
* `lex.yy.c` *(generated by Flex)*

### Features

* Keyword recognition
* Identifier detection
* Numeric constants
* Operators
* Delimiters
* Comments
* Token statistics
* Summary report generation

### Sample Output

```text
KEYWORD: int
IDENTIFIER: x
OPERATOR: =
NUMBER: 5
DELIMITER: ;

========== TOKEN SUMMARY ==========
Keywords      : 1
Identifiers   : 1
Numbers       : 1
Operators     : 1
Delimiters    : 1
Comments      : 0
Total Tokens  : 5
```

### Concepts Covered

* Token classification
* Source code analysis
* Compiler front-end implementation
* Lexical statistics

---

## 🔹 Lab 4 — Arithmetic Expression Evaluator (Flex + Bison)

A parser capable of evaluating arithmetic expressions while respecting operator precedence and associativity.

### Files

* `key.l`
* `y.y`

### Features

* Integer arithmetic
* Addition
* Subtraction
* Multiplication
* Division
* Parentheses
* Operator precedence
* Division-by-zero handling
* Syntax error reporting

### Example

Input

```text
3+4*2
(3+4)*2
10/5+7
```

Output

```text
Result = 11
Result = 14
Result = 9
```

### Concepts Covered

* Parser generation
* Context-Free Grammar
* Semantic actions
* Operator precedence
* Expression evaluation

---

## 🔹 Lab 5 — If-Else Parser Using Flex and Bison

A parser for validating simple **if-else** statements and resolving the classic **dangling-else** ambiguity.

### Files

* `ifelse.l`
* `ifelse.y`

### Features

* If statements
* Else statements
* Nested conditions
* Assignment statements
* Relational operators
* Syntax validation
* Error reporting

### Example

```text
if(a>b) x=y;
if(a>b) x=y; else x=z;
```

### Concepts Covered

* Grammar design
* Shift/Reduce parsing
* Dangling else problem
* Parser generation
* Syntax checking

# ⚙️ Prerequisites

Install the following software before running the experiments.

* GCC Compiler
* Flex (or WinFlexBison)
* Bison (or WinFlexBison)
* PowerShell / Command Prompt / Linux Terminal

---

# 🔍 Verify Installation

```powershell
gcc --version
flex --version
bison --version
```

# 🚀 Building the Programs

## Lab 1

```powershell
cd Lab_1

gcc sum_program.c -o sum_program.exe
gcc circle_area.c -o circle_area.exe
```

---

## Lab 2

```powershell
cd Lab_2

flex tokenizer.l
gcc lex.yy.c -o tokenizer.exe
```

---

## Lab 3

```powershell
cd Lab_3

flex token_counter.l
gcc lex.yy.c -o lexer.exe
```

---

## Lab 4

```powershell
cd Lab_4

bison -d y.y
flex key.l
gcc y.tab.c lex.yy.c -o evaluator.exe
```

*(For Windows users with WinFlexBison)*

```powershell
win_bison -d y.y
win_flex key.l
gcc y.tab.c lex.yy.c -o evaluator.exe
```

---

## Lab 5

```powershell
cd Lab_5

bison -d ifelse.y
flex ifelse.l
gcc ifelse.tab.c lex.yy.c -o ifelsechecker.exe
```

# 🎯 Learning Outcomes

After completing these laboratory experiments, students will be able to:

* Understand the phases of a compiler
* Write and compile C programs using GCC
* Design lexical analyzers using Flex
* Generate parsers using Bison
* Recognize programming language tokens
* Perform lexical analysis
* Design Context-Free Grammars (CFG)
* Implement syntax validation
* Evaluate arithmetic expressions
* Understand operator precedence
* Analyze source code using compiler front-end techniques
