# Compiler Lab

A collection of Compiler Design laboratory experiments implemented using **C Programming**, **Flex**, and **Bison**. These labs demonstrate compiler front-end concepts, lexical analysis, parsing, expression evaluation, and token reporting.

---

## Repository Structure

### Lab 1 – Basic C Programs

Introduction to C programming through beginner arithmetic applications.

#### Files

* [Lab_1/sum_program.c](Lab_1/sum_program.c) – Sum of two numbers
* [Lab_1/circle_area.c](Lab_1/circle_area.c) – Area of a circle

#### Features

* Read two integers from user input
* Perform addition
* Calculate circle area using `π × r²`
* Display results with `printf`

#### Build

```powershell
cd Lab_1
gcc sum_program.c -o sum_program.exe
gcc circle_area.c -o circle_area.exe
```

#### Run

```powershell
.\sum_program.exe
.\circle_area.exe
```

#### Sample Output

```text
Enter two numbers: 4 5
Sum = 9

Enter radius: 3
Area = 28.26
```

### Lab 2 – Lexical Analyzer Using Flex

A lexer that scans input and identifies token categories using Flex.

#### Files

* [Lab_2/tokenizer.l](Lab_2/tokenizer.l)

#### Recognized Tokens

* Keywords: `int`, `float`, `if`, `else`, `return`
* Identifiers
* Numbers
* Operators
* Separators / delimiters

#### Build

```powershell
cd Lab_2
win_flex -o tokenizer.c tokenizer.l
gcc tokenizer.c -o tokenizer.exe
```

#### Run

```powershell
.\tokenizer.exe
```

Enter C-style input and finish with:

```text
Ctrl + Z
Enter
```

#### Sample Output

```text
Keyword: int
Identifier: main
Separator: (
Separator: )
Separator: {
Keyword: return
Number: 5
Separator: ;
Separator: }
```

### Lab 3 – Token Counter Using Flex

A lexer that counts tokens and prints a summary report.

#### Files

* [Lab_3/token_counter.l](Lab_3/token_counter.l)
* `Lab_3/lex.yy.c` *(generated by Flex)*

#### Features

* Recognizes keywords, identifiers, numbers, operators, delimiters, and comments
* Prints each token as it is detected
* Produces a final token summary

#### Build

```powershell
cd Lab_3
flex token_counter.l
gcc lex.yy.c -o lexer.exe
```

#### Run

```powershell
.\lexer.exe
```

#### Sample Output

```text

IDENTIFIER: main
DELIMITER: (
DELIMITER: )
DELIMITER: {
KEYWORD: int
IDENTIFIER: x
OPERATOR: =

DELIMITER: }

===== TOKEN SUMMARY =====

Numbers     : 1
Operators   : 1
```

### Lab 4 – Arithmetic Expression Evaluator Using Flex and Bison

A parser for arithmetic expressions with precedence and error handling.

#### Files

* [Lab_4/key.l](Lab_4/key.l)
* [Lab_4/y.y](Lab_4/y.y)

#### Features

* Supports `+`, `-`, `*`, `/`
* Supports parentheses
* Respects operator precedence and associativity
* Handles division by zero
* Reports syntax errors

#### Build

```powershell
cd Lab_4
win_bison -d y.y
win_flex key.l
gcc y.tab.c lex.yy.c -o evaluator.exe
```

#### Run

```powershell
.\evaluator.exe
```

#### Example Input

```text
3+4*2
(3+4)*2
10/5+7
```

#### Sample Output

```text
Result = 11
Result = 14
Result = 9
```

### Lab 5 – If-Else Statement Parser

A parser that validates simple `if` and `if-else` statements.

#### Files

* [Lab_5/ifelse.l](Lab_5/ifelse.l)
* [Lab_5/ifelse.y](Lab_5/ifelse.y)

#### Features

* Parses `if` and `if-else` statements
* Resolves dangling else using precedence rules
* Prints validity for each input statement

#### Build

```powershell
cd Lab_5
bison -d ifelse.y
flex ifelse.l
gcc ifelse.tab.c lex.yy.c -o ifelsechecker.exe
```

#### Run

```powershell
.\ifelsechecker.exe
```

#### Sample Input

```text
if (a>b) x=y;
if (a>b) x=y; else x=z;
```

#### Sample Output

```text
valid
valid
```

## How to Build All Labs

Build each lab separately from its folder:

```powershell
cd Lab_1
gcc sum_program.c -o sum_program.exe
gcc circle_area.c -o circle_area.exe

cd ..\Lab_2
win_flex -o tokenizer.c tokenizer.l
gcc tokenizer.c -o tokenizer.exe

cd ..\Lab_3
flex token_counter.l
gcc lex.yy.c -o lexer.exe

cd ..\Lab_4
win_bison -d y.y
win_flex key.l
gcc y.tab.c lex.yy.c -o evaluator.exe

cd ..\Lab_5
bison -d ifelse.y
flex ifelse.l
gcc ifelse.tab.c lex.yy.c -o ifelsechecker.exe
```

* Understand lexical analysis and parsing
* Create Flex lexer specifications
* Build Bison grammars for parsing
* Evaluate arithmetic expressions with precedence
* Handle syntax errors and ambiguous grammar rules
* Compile and run compiler front-end programs
