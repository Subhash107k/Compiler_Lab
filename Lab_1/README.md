# Lab 1: Basic C Programs

This folder contains two simple C programs for compiler lab practice.

Files:

- [sum_program.c](sum_program.c)
- [circle_area.c](circle_area.c)

Build with GCC:

```powershell
gcc sum_program.c -o sum_program.exe
gcc circle_area.c -o circle_area.exe
```

Run the programs:

```powershell
.\sum_program.exe
.\circle_area.exe
```
