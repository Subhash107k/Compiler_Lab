# Lab 1 – Basic C Programs

## Overview

This lab contains two beginner-level C programs created for Compiler Lab practice. The programs demonstrate basic input, output, arithmetic operations, and the use of variables in C programming.

## Programs Included

### 1. sum_program.c
A simple program that:
- Accepts two numbers from the user
- Calculates their sum
- Displays the result

### 2. circle_area.c
A program that:
- Accepts the radius of a circle from the user
- Calculates the area using the formula:

Area = π × r²

- Displays the calculated area

## Compilation

Use the GCC compiler to build the programs:

```powershell
gcc sum_program.c -o sum_program.exe
gcc circle_area.c -o circle_area.exe
```

## Execution

Run the compiled executables using:

```powershell
.\sum_program.exe
.\circle_area.exe
```

## Learning Outcomes

After completing this lab, students will be able to:

- Write and compile basic C programs
- Use variables and data types
- Perform arithmetic calculations
- Accept user input using `scanf()`
- Display output using `printf()`
- Understand the basic program structure in C

## Requirements

- GCC Compiler
- Windows PowerShell or Command Prompt
- Basic knowledge of C programming
