# Lab 3 – Token Counter Using Flex

## Overview

This project demonstrates lexical analysis using Flex (Fast Lexical Analyzer Generator). The lexer scans C source code, identifies various token types, and displays them. It also maintains counts of each token category and generates a summary after processing the input.

## Features

* Recognizes C language keywords
* Identifies user-defined identifiers
* Detects numeric constants
* Recognizes operators and delimiters
* Supports single-line comments
* Displays each token as it is recognized
* Generates a token summary report

## Project Structure

| File               | Description                                    |
| ------------------ | ---------------------------------------------- |
| `token_counter.l`  | Flex specification file containing lexer rules |
| `lex.yy.c`         | C source file automatically generated by Flex  |
| `lexer.exe`        | Executable generated after compilation         |
| `sample_input.txt` | Sample input source code for testing           |

## Token Categories

The lexer recognizes and counts the following token types:

* Keywords
* Identifiers
* Numbers
* Operators
* Delimiters
* Comments
* Unknown Tokens

## Requirements

* Flex (WinFlexBison on Windows)
* GCC Compiler (MinGW/MSYS2)

## Compilation

Generate the lexer source code:

```powershell
flex token_counter.l
```

Compile the generated source:

```powershell
gcc lex.yy.c -o lexer.exe
```

## Execution

### Interactive Mode

Run the lexer:

```powershell
.\lexer.exe
```

Enter C source code and finish input using:

```text
Ctrl + Z
Enter
```

### File Input Mode

Create a sample source file:

```c
int main()
{
    int x = 10;
    return x;
}
```

Run:

```powershell
.\lexer.exe < sample_input.txt
```

## Learning Outcomes

After completing this lab, students will be able to:

* Understand the role of lexical analysis in compiler design
* Write token recognition rules using Flex
* Generate lexical analyzers automatically

* Count and analyze token occurrences
